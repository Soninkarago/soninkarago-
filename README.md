# SoninkaraGo

Version de production orientée mobile.

- Interface épurée et cohérente
- Aucun emoji dans l’interface
- Palette limitée et accessible
- Parcours passager, chauffeur et administration conservés
- Paiement, géolocalisation et logique serveur conservés
- Pages légales harmonisées

Déploiement prévu via GitHub et Render.
