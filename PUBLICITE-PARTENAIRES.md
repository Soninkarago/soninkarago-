## Règle commerciale
La colonne « base conseillée » est le point de départ de négociation. Le prix final peut être supérieur selon :
- exclusivité sectorielle ;
- présence site + application ;
- emplacement premium ;
- volume réel d’utilisateurs/impressions ;
- durée de campagne ;
- droits d’image/co-branding ;
- présence sur événements SoninkaraGo.

Le prix final est enregistré campagne par campagne dans l’administration.

## Garde-fous
- Une publicité doit rester clairement identifiée comme sponsorisée.
- Aucune publicité ne doit bloquer une commande, une course ou une fonction de sécurité.
- Aucun profilage individuel n’est utilisé dans le module first-party actuel.
- Toute régie tierce future impose une nouvelle revue confidentialité/CDP/App Store/Google Play.
